# DomesticPal

A Flutter + Firebase mobile app that connects households with domestic workers — maids, cooks, and babysitters. Customers can find and hire help, while workers can create profiles and get discovered.

## Features

- **Two user roles** — separate flows for customers and workers (employees)
- **Authentication** — email/password sign-up and login via Firebase Auth
- **Worker profiles** — job profile (maid, cook, babysitter), gender, location, work experience, and ratings
- **Cloud data** — customer and worker details stored in Cloud Firestore
- **Ratings** — customers can rate workers

## Tech Stack

- **Framework:** Flutter (Dart)
- **Backend:** Firebase Authentication + Cloud Firestore
- **Platforms:** Android & iOS
